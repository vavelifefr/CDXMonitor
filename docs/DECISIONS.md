# DECISIONS — журнал технических решений

| Дата | Решение | Причина |
|---|---|---|
| 2026-09-28 | Источник — только локальные файлы Codex (JSONL + опц. SQLite ro); без API/сети/перехвата | Так устроен эталон; read-only = безопасно для сессий и авторизации (AUDIT §2) |
| 2026-09-28 | Стек: TS + Node 24, React + Vite, SSE, `node:sqlite` | Node 24 и npm проверены локально; `node:sqlite` без нативных аддонов; SSE достаточно для 1 Hz пуша |
| 2026-09-28 | Порт семантики Python-монитора 1-в-1 (TURN/TASK/ROLLOUT, max-согласование, TASK-baseline) | Проверенная защита от двойного счета и потери compaction-usage; сверка A1 |
| 2026-09-28 | `compacted` — первоклассное событие; тексты истории не читаем | Закрывает пробел исходника (счетчик/время compaction); приватность (METRICS §6) |
| 2026-09-28 | Secondary (weekly) лимит — первоклассный | Исходник его теряет (AUDIT §4.1); источник достоверен |
| 2026-09-28 | `cache_write_input_tokens` — отдельная строка | Поле есть в схеме, исходник игнорирует |
| 2026-09-28 | SQLite Codex — опциональный изолированный адаптер (`mode=ro`) | Схема недокументирована и может меняться; падение адаптера не роняет коллектор |
| 2026-09-28 | Демо-режим только на синтетике, с плашкой DEMO | Запрет на фиктивные данные в реальном мониторинге (требование SDD) |
| 2026-09-28 | Boot-first: `boot.html` без сервера + кнопка через протокол `cdxmonitor://start` (HKCU) + опрос `/api/health` (CORS `*`) с автопереходом | Требование пользователя: старт виджета без запущенного сервера; браузер не может порождать процессы — нужен кастомный протокол + install-скрипт |
| 2026-09-28 | E2: сервер на stdlib `node:http`, bind 127.0.0.1 | Ноль runtime-зависимостей |
| 2026-09-28 | Порт по умолчанию 8765 (был 17869); занятый порт — явная ошибка, без автопереключения | Требование переносимой сборки; предсказуемый URL для панели Codex |
| 2026-09-28 | Release-пакет `release/CDXMonitor/` — на Этапе 8; данные в отдельном `data/`; Node runtime (PATH vs bundle) решить на E8 | Требование ставить после разработки; установка только после утверждения расположения |
| 2026-09-28 | Реестр установки `.cdxmonitor-install.json`, атомарно + `.bak`, без дублей | Идемпотентные обновления с сохранением data/настроек; имя не clash с config и маркером |
| 2026-09-28 | Автооткрытие вкладки: только fallback (команда + стабильный URL + инструкция); внедрение запрещено | Исследование: документированного механизма нет (In-app browser открывается вручную/по клику URL/Ctrl+Shift+B; Actions — только скрипты терминала; `codex://` — лишь запрос фичи) |
| 2026-09-28 | Тоглы «автозапуск сервера» / «автооткрытие вкладки» независимы, default off | Требование; второй действует только при появлении документированного механизма |
| 2026-09-28 | Установленные ссылки — абсолютные `file:///` (реврайт в install, `.bak`, идемпотентно) + shim на серверные алиасы при HTTP | Требование машинно-специфичных путей; браузеры блокируют http→file, относительные ломались |
| 2026-09-28 | Lock-файл против молчаливого sharing порта (SO_REUSEADDR на Windows) | Наблюдены ответы от дублирующихся процессов; второй экземпляр отказывается явно |
| 2026-09-28 | Текстовые файлы проекта — UTF-8 с BOM | Глобальная политика кодировок среды |
