# AGENTS.md — инструкции для LLM-агентов CDXMonitor

1. Порядок чтения: `docs/STATE.md` → `docs/SPEC.md` → `docs/ARCHITECTURE.md` → `docs/METRICS.md`
→ `docs/AUDIT.md` → `docs/DECISIONS.md`. Не пересказывать их в чате без нужды.
2. Исходник `codex-context-monitor-main/` — только чтение. Данные `~/.codex` — только чтение
(SQLite открывать `mode=ro`). Секреты и тексты диалогов не читать, не логировать, не коммитить.
3. Рабочая директория — только `CDXMonitor/`. Этапы E1–E8 из ARCHITECTURE §7, по одному за раз.
Каждый этап: цель → реализация → `tsc` + smoke + регрессия → запись в `docs/STATE.md`.
4. Тесты — только синтетические фикстуры. Демо-режим отделен флагом и плашкой DEMO.
5. Оценочные метрики — с бейджем EST; отсутствующие — N/A, не нули. Выдуманные данные запрещены.
6. Текстовые файлы — UTF-8 с BOM; перед отправкой проверять кодировку (см. skill `encoding-guard`).
7. Контрольная точка: без явной команды не начинать следующий этап после завершения текущего.
