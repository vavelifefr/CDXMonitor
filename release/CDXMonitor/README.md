# CDXMonitor — переносимая сборка

Локальный монитор статистики Codex Desktop. Сервер + веб-интерфейс для боковой панели Codex.

## Состав папки

| Путь | Назначение |
|---|---|
| `web/` | Интерфейс: монитор, `boot.html` (старт без сервера), `help.html` (эта инструкция), `pages/` |
| `server/` | Локальный сервер и сборщик статистики (Node.js, без внешних CDN в рантайме) |
| `config/cdxmonitor.json` | Настройки: порт (default 8765), bind, каталог сессий, `dataDir` |
| `data/` | Ваши данные: история, PID-файл. При обновлении не затирается |
| `start.cmd` / `stop.cmd` | Запуск двойным кликом / остановка |
| `install.ps1` / `uninstall.ps1` | Установка и удаление |
| `setup.exe` | Стандартный запуск установки (двойной клик, вызывает `install.ps1`) |
| `codex-plugin/` | Плагин Codex: скиллы `$cdx-stats` / `$cdx-open` (ставится установщиком с согласия) |
| `.cdxmonitor-release.json` | Маркер пакета (проверяется установщиком) |

## Установка

Вариант А (рекомендуется): скопируйте эту папку целиком в утвержденный каталог:

- `%LOCALAPPDATA%\OpenAI\Codex\CDXMonitor` (рядом с Codex), или
- `%LOCALAPPDATA%\CDXMonitor` (запасной).

Вариант Б: запустите `install.ps1` (правой кнопкой → «Выполнить с помощью PowerShell»)
и выберите расположение. Существующая папка `data/` при обновлении сохраняется.
Установщик также регистрирует протокол `cdxmonitor://` (кнопка на boot-странице);
удаляется вместе с пакетом через `uninstall.ps1`.
Файлы самого Codex (`bin`, `runtimes` и др.) установщик не трогает.

Требуется Node.js 24+ в PATH (проверяется при старте с понятной ошибкой).

## Команда cdxm

Установщик предлагает добавить папку в пользовательский PATH — после этого в любом
терминале доступна команда `cdxm`: без аргументов поднимает сервер и печатает URL
(клик по URL во встроенном терминале Codex открывает его во встроенном браузере),
`--open` — открыть в браузере по умолчанию, `stop` / `status` — остановить / статус,
`help` — краткая справка. Удаление пакета убирает папку и из PATH.

## Запуск и подключение к Codex

1. Двойной клик `start.cmd`.
2. Во встроенном браузере правой панели Codex откройте `http://127.0.0.1:8765/`
   (адрес и порт — из `config/cdxmonitor.json`).
3. Показатели обновляются сами каждую секунду.
4. Остановка — двойной клик `stop.cmd`.

Сервер работает полностью скрыто (без окна консоли). Диагностика — `data/cdxmonitor.log`.
Закрытие окна консоли больше не требуется: останавливайте только через `stop.cmd`.

Удобный вариант: действие Start CDXMonitor через Local Environments → Actions
(настройки Codex → действие запускает `start.cmd` во встроенном терминале).
Вкладка с локальным адресом может не восстанавливаться после перезапуска Codex —
в этом случае просто откройте адрес заново.

## Если сервер не стартовал

- Окно сразу закрылось — смотрите ошибку (скорее всего нет Node.js или порт занят).
- Порт занят — сервер сообщает об этом явно; освободите порт или смените его в
  `config/cdxmonitor.json`.
- Подробности — `/help` на запущенном сервере и `data/` (PID-файл).

## Удаление

Запустите `uninstall.ps1` из папки установки: удаляются только файлы CDXMonitor,
папка `data/` сохраняется (полное удаление — с флагом `-RemoveData`).
