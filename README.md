# CDXMonitor

Локальный монитор статистики Codex Desktop с веб-интерфейсом для боковой панели Codex.
Открывается по `127.0.0.1:<порт>` во встроенном браузере. Только чтение данных Codex, без сети и патчей.

Статус: Этап 0 (аудит и проектирование) завершен, архитектура ждет утверждения. Реализации пока нет.

## Документы

- `docs/AUDIT.md` — аудит исходного PowerShell/TUI-монитора и живых данных Codex.
- `docs/METRICS.md` — каталог метрик (достоверные / вычисляемые / оценочные / недоступные).
- `docs/SPEC.md` — функциональная спецификация и критерии приемки A1–A7.
- `docs/ARCHITECTURE.md` — стек, модули, план этапов E1–E8.
- `docs/DECISIONS.md` — журнал решений.
- `docs/STATE.md` — текущее состояние и следующий шаг.
- `AGENTS.md` — инструкции для LLM-агентов.
